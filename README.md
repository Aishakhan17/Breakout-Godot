# Breakout-Godot
Breakout in godot

## Gameplay 
You get three chances to destroy all the bricks to clear the level. Grey bricks explode - use them to speed things up. 
Ball now takes keyboard input;  use the arrow keys to set the angle to launch and press enter to launch it. 
Paddle moves with left and right keys. Cannot pause game at the minute but there are 5 levels now. :))

## Status
A very small indie game built to learn godot. Game doesn't have state so every relaunch launches it from level 1. :)
