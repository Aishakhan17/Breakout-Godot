# Breakout-Godot
Breakout in godot

## Gameplay 
You get three chances to destroy all the bricks to clear the level. Grey bricks explode - use them to speed things up. 
Ball now takes keyboard input;  use the arrow keys to set the angle to launch and press space to launch it. 
Press esc to pause and unpause the game.
Paddle moves with left and right keys. Game only has 5 levels at the minute and will probably crash after that. 
Still trying to decide how I want to go about it. :))

## Status
A very small indie game built to learn godot. Game doesn't have state so every relaunch launches it from level 1. :)
